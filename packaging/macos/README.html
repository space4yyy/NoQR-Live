OBS QR Shield 安装说明

Apple 芯片 Mac · macOS 13+ · OBS 32 · 已验证 OBS 32.2.2。Intel Mac 和 Windows 不适用。

安装

  1. 把 OBS.app 放入“应用程序”文件夹。
  2. 退出 OBS，双击 PKG 安装包，按提示继续。插件安装给当前用户。
  3. 重新打开 OBS，在采集卡来源的“滤镜 → 效果滤镜”中添加“二维码自动遮挡 / QR Shield”。

高斯 Blur 的强度范围为 60–100，默认 80；也可选择黑块或自定义图片。同屏多个已识别二维码会分别遮挡。检测保持原分辨率，视频来源与 OBS 需使用 SDR。

安全确认

当前安装包未经过 Developer ID 签名和 Apple 公证。若 macOS 阻止打开，先确认来源和文件未遭篡改，再按 Apple 官方说明，在“系统设置 → 隐私与安全性”中针对这个安装包确认“仍要打开”。请勿全局关闭系统安全保护。安装器获准打开也不保证所有 Mac 都能加载未公证插件。

更新与卸载

退出 OBS 后再次运行新版 PKG 即可更新。卸载时退出 OBS，然后删除：

~/Library/Application Support/obs-studio/plugins/obs-qrcode.plugin

不会更改 OBS 场景或声音设置。检测仍可能漏报，Blur 不能保证所有扫码器都无法解码，请先本地录制验证。音频同步偏移需按实际画面延迟自行调整。
